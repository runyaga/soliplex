{"code": "h = df_create([{\"name\": \"Alice\", \"age\": 30}])\nprint(h)"}

## Tool Functions Available Inside execute_python (ONLY these exist)
Tool functions are pre-loaded. DO NOT import them.
CRITICAL: Positional arguments ONLY. Keyword arguments will crash.
CRITICAL: Do NOT invent functions. If it is not listed below, it does NOT exist.

### Data functions (all return numeric handle or list):
- df_create(data_list) -> handle
- df_filter(handle, column_str, op_str, value) -> handle  # op: "==",">","<",">=","<=","!=","contains"
- df_sort(handle, column_str, ascending_bool) -> handle
- df_group_agg(handle, group_cols_list, agg_map) -> handle  # agg_map: {"col": "sum"|"mean"|"min"|"max"|"count"}
- df_head(handle, n_int) -> list of row dicts
- df_tail(handle, n_int) -> list of row dicts
- df_to_list(handle) -> list of row dicts
- df_columns(handle) -> list of column name strings
- df_shape(handle) -> [rows, cols]
- df_describe(handle) -> dict of stats per numeric column
- df_select(handle, columns_list) -> handle
- df_drop(handle, columns_list) -> handle
- df_rename(handle, mapping_dict) -> handle  # {"old_name": "new_name"}
- df_add_column(handle, name_str, values_list) -> handle
- df_merge(handle1, handle2, on_list, how_str) -> handle  # on: ["col"], how: "inner"|"left"
- df_concat(handles_list) -> handle  # takes a list of handles, e.g. [0, 1]
- df_fillna(handle, value) -> handle
- df_nlargest(handle, n_int, column_str) -> handle
- df_nsmallest(handle, n_int, column_str) -> handle
- df_mean(handle, column_str) -> float
- df_sum(handle, column_str) -> float
- df_min(handle, column_str) -> float or str
- df_max(handle, column_str) -> float or str
- df_std(handle, column_str) -> float
- df_unique(handle, column_str) -> list
- df_value_counts(handle, column_str) -> dict
- chart_create(config_dict) -> handle  # {"handle": 0, "type": "bar"|"line"|"scatter", "x": "col", "y": "col"}

- NO keyword args on built-ins: `sorted(x, key=...)`, `max(x, key=...)` will crash.
- NO nested subscript assignment: `d[k1][k2] = val` will crash. Use a temp variable instead.
- NO `del` statement.
- NO File I/O (open, read, write).
- NO Network access.
- NO eval(), exec(), globals(), locals().
- NO async/await.
- NO classes.
- NO pandas, numpy, or any library. Use ONLY the listed tool functions.
